# 🎮 Simon Says – Memory Game

A fun and interactive **Simon Says Memory Game** built using **HTML, CSS, and Vanilla JavaScript**.

The game tests your memory and concentration by generating a sequence of colored buttons. Your goal is to remember the sequence and repeat it correctly. As you progress, the sequence becomes longer and the game gets more challenging! 🧠🎯

## 🎯 How to Play

1. Open the game in your browser.
2. Press the **Start** button or follow the game's starting instruction.
3. Watch the sequence of colored buttons carefully.
4. Remember the order in which the buttons appear.
5. Repeat the same sequence by clicking the buttons.
6. If your answer is correct, you move to the next level.
7. Each new level adds another step to the sequence.
8. If you press the wrong button, the game ends.
9. Restart the game and try to beat your previous score! 🏆

## 🧠 Game Logic

The game follows a simple sequence-based memory system:

   text
Start Game
     ↓
Generate Random Color
     ↓
Show Sequence
     ↓
Player Repeats Sequence
     ↓
Is Sequence Correct?
    ↙       ↘
  YES        NO
   ↓          ↓
Next Level   Game Over
   ↓
Add New Color
   ↓
Show New Sequence
